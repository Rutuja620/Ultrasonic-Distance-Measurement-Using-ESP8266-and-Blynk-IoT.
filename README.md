# Ultrasonic Distance Measurement Using ESP8266 and Blynk IoT

## Description
This project uses the HC-SR04 ultrasonic sensor with ESP8266 NodeMCU to measure the distance of nearby objects. The measured distance values are displayed on the Arduino IDE Serial Monitor and also sent to the Blynk IoT Cloud platform for real-time remote monitoring.

## Components Used
- ESP8266 NodeMCU
- HC-SR04 Ultrasonic Sensor
- Jumper Wires
- Breadboard
- USB Cable

## Software Used
- Arduino IDE
- Blynk IoT Platform

## Features
- Real-time distance measurement
- Wireless monitoring using Wi-Fi
- Serial Monitor display
- Blynk cloud integration
- Simple IoT-based sensing application

## Working Principle
1. Ultrasonic sensor sends ultrasonic waves.
2. Waves reflect back after hitting an object.
3. ESP8266 calculates the distance using echo time.
4. Distance value is displayed on Serial Monitor.
5. Data is sent to Blynk IoT Cloud for remote monitoring.

## Applications
- Obstacle Detection
- Distance Measurement
- Smart Parking Systems
- Water Level Monitoring
- Robotics Projects

## Outcome
Successfully measured object distance using HC-SR04 and monitored the readings remotely using ESP8266 and Blynk IoT Cloud.
